# Notewise AI

Notewise AI is an AI-powered document platform that lets users upload documents and interact with them through an AI chatbot. Users can upload PDFs, handwritten notes, Markdown files, text files, and other supported documents, then ask questions and get answers based on their sources.

It also includes an AI Playground that can turn uploaded sources into different formats such as quizzes, flashcards, notes, summaries, podcasts, audio, and videos.

## Features

- **AI Chat:** Ask questions about uploaded documents and get answers based on the user's sources.
- **Smart Query Routing:** Automatically identifies the type of query and routes it to the appropriate search or conversation flow.
- **Fast Search:** Quickly finds relevant information from uploaded documents for simple queries.
- **Deep Search:** Handles complex queries by searching and understanding information across documents.
- **RAG:** Uses retrieval-augmented generation to provide relevant context from uploaded sources while answering questions.
- **AI Playground:** Generate quizzes, flashcards, notes, summaries, podcasts, audio, and videos directly from uploaded sources.
- **AI Memory:** Maintains useful conversation context using summarization.
- **Authentication:** Secure user authentication and account management.
- **Cloud Storage:** Documents and application data are stored using cloud services.

## Use Cases

### For Students
Upload class notes, study material, or reference documents and use Notewise AI to:
- Ask questions about the material
- Quickly revise topics
- Generate quizzes and flashcards
- Create summaries and notes
- Turn study material into podcasts or videos

### For Organizations
Notewise AI can be used to work with large collections of documents, reports, and other files. Users can quickly find specific information, numbers, tables, or sections without manually searching through every document.
